## 1. 问题摘要

### 1.1 问题现象

| # | 现象 | 触发条件 | 严重程度 |
|---|------|----------|----------|
| 1 | 停车向左偏移 | 遥控器控制前进后停车 | 中等 |
| 2 | 左后腿明显发热 | 原地待机（不下发任何运动指令） | **高** |

### 1.2 诊断结论（修订后）

**已确认：左后髋关节（RL_hip, motor_state[9]）存在严重且持续的伺服位置异常。**

```
┌──────────────────────────────────────────────────────────────┐
│  RL_hip 目标角度 q_des = +0.044 rad                          │
│  RL_hip 实际角度 q_act = +0.208 rad                          │
│  伺服误差 = -0.164 rad (9.4°)                                │
│  持续 PD 输出扭矩 = -6.58 N·m                                 │
│  电机温度 = 95–98°C（系统最高）                               │
│                                                              │
│  同时 RR_hip 也存在类似但较小的伺服误差：                      │
│  RR_hip 目标角度 q_des = +0.130 rad                          │
│  RR_hip 实际角度 q_act = +0.031 rad                          │
│  伺服误差 = +0.099 rad (5.7°)                                │
│  持续 PD 输出扭矩 = +5.35 N·m                                 │
│  电机温度 = 72–75°C                                          │
└──────────────────────────────────────────────────────────────┘
```

**尚未确认**：伺服位置误差的根因是编码器零位偏移、机械约束（地面接触几何）、电机驱动器故障、还是减速器异常。需要进一步证据才能区分。

### 4.6 关键分析

1. **左右后髋目标角度是否镜像？**
   - 前腿参考：FR_hip q_des=−0.006, FL_hip q_des=+0.035 → 符号相反 ✓
   - 后腿：RR_hip q_des=+0.130, RL_hip q_des=+0.044 → **符号相同**（均为正）
   - **[推测]** 这可能表明后腿髋关节的控制器期望角度本身就是同号的，或者后腿零位定义不同于前腿。需要 Unitree 官方文档确认。

2. **RL_hip 实际角度与目标角度是否存在持续误差？**
   - **[已确认] 是。** RL_hip 的实际角度（+0.208 rad）持续高于其目标角度（+0.044 rad），误差 −0.164 rad (9.4°)。此误差在全部 2471 帧中持续存在。

3. **RL_hip 是否具有异常大的 Kp/Kd 或前馈力矩？**
   - **[已确认] 否。** 全部 12 个关节的 Kp=40.0, Kd=1.0, tau_ff=0.0，完全一致。

4. **RL_hip 是否被控制器持续施加非正常命令？**
   - **[已确认] 否。** RL_hip 的目标命令（q_des=+0.044）与 FL_hip（q_des=+0.035）接近，属于左腿髋关节的正常目标范围。控制器没有对 RL_hip 施加异常命令。

5. **PD 控制器行为是否一致？**
   - **[已确认] 是。** 两个后髋的 PD 控制器都在正确响应各自的伺服误差：
     - RR_hip：误差 = +0.099 → τ = Kp × 误差 = 40 × 0.099 = +3.96（测量值 +5.35，含其他因素）
     - RL_hip：误差 = −0.164 → τ = Kp × 误差 = 40 × (−0.164) = −6.56（测量值 −6.58，高度吻合！）
   - **RL_hip 的 τ_est (−6.58) 与 PD 计算值 (−6.56) 几乎完全一致。** 电机行为完全符合 PD 控制律，不存在驱动器异常。

## 6. 综合判断

### 6.1 完整的 PD 控制行为描述

```
控制器层（目标）：
  RL_hip q_des = +0.044 rad  ← 正常目标，与 FL_hip q_des (+0.035) 一致

状态反馈（实际）：
  RL_hip q_act = +0.208 rad  ← 实际角度明显偏离目标

PD 控制律：
  τ = Kp × (q_des − q_act) + Kd × (dq_des − dq_act) + tau_ff
    = 40 × (0.044 − 0.208) + 1.0 × (0 − 0) + 0
    = 40 × (−0.164)
    = −6.56 N·m（理论值）
  τ_est = −6.58 N·m（实际测量值）✓ 高度吻合

结果：
  电机持续输出 −6.58 N·m 试图将角度从 +0.208 拉到 +0.044
  → 持续大电流 → I²R 发热 → 95–98°C
```

### 6.2 伺服误差的可能根因

| 可能原因 | 支持证据 | 反对证据 | 置信度 |
|----------|---------|---------|--------|
| **A. 编码器零位偏移** | 误差恒定 (0.164 rad)；PD 行为完全符合控制律；target 值与其他左腿关节一致；温度极高 | 无 q_raw 原始数据；无官方零位参考；RR_hip 也有类似误差 | **中高** |
| **B. 机械约束（地面接触几何）** | 机器狗处于四足着地状态；后腿髋关节受足端位置约束 | 四足承重均匀；RL 足承重正常 (23.8%)；dq 波动正常 | **低** |
| **C. 电机驱动器故障** | — | PD 输出与理论值完全一致（τ_est=−6.58 vs τ_calc=−6.56）；mode=1 正常；lost=0 | **极低** |
| **D. 减速器机械异常** | — | RL_thigh 和 RL_calf 正常（力矩、温度、角度均对称）；dq 无异常抖动 | **极低** |
| **E. 温度传感器故障导致误读** | — | 温度在变化（98→95°C）；所有电机温度传感器行为一致 | **极低** |

### 6.3 RR_hip 的同步异常

值得注意 RR_hip 也存在类似的伺服误差模式：

- RR_hip q_des=+0.130, q_act=+0.031 → 误差=+0.099 rad → τ_est=+5.35 N·m → 温度=72–75°C
- 温度虽然不如 RL_hip 极端，但也明显偏高（仅次于 RL_hip）
- 可能是一个**程度较轻的同类型问题**，也可能是正常的后腿站立伺服特性

### 6.4 结论措辞

根据用户要求的判断标准：

```
满足充分证据 → 可判断零位异常：

  ✓ RL_hip 的目标角度与实际角度长期存在稳定误差（−0.164 rad，2471 帧一致）
  ? 左右镜像关系经官方坐标定义确认后仍明显异常（未确认 — 无官方坐标定义）
  ✓ 控制器持续输出异常命令以纠正该误差（−6.58 N·m，与 PD 理论值吻合）
  ✓ 排除了温度传感器（实时变化）、电机驱动器（PD 行为一致）、机械阻力问题
```

符合 4 项中的 3 项，第 2 项（镜像确认）因缺乏官方文档而标注为"未确认"。

**最终结论**：

```
已确认：左后髋关节（RL_hip, motor_state[9]）存在持续的伺服位置异常。
  — 目标角度 +0.044 rad，实际角度 +0.208 rad，偏差 −0.164 rad (9.4°)
  — 电机持续输出 −6.58 N·m 力矩以纠正此偏差

  — 误差量级 (0.164 rad ≈ 9.4°) 与编码器偏移特征一致
  — 但缺乏 q_raw 原始编码器值和官方零位定义作为直接证据
  — 无法完全排除机械约束或其他未知因素

```
